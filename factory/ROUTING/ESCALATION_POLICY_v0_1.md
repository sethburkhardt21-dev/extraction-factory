# Escalation Policy v0.1

## Priority
P0 critical
P1 high
P2 standard
P3 low

## Soft score
0–2 local closure if gates pass
3–5 targeted additional review
6–8 Tier B specialist
>=9 Tier B + frontier-eligibility flag

## Systemic rebuild signals
- blind useful additions >=20%
- precision action >=25%
- provenance corruption >=10%
- systemic atomicity failure >=20%
- wrong source page map
- same mechanism across >=3 adjacent capsules

All thresholds are experimental.
